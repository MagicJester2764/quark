# Phase 8a — Wayland MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `weston-simple-shm`, unmodified, draws on Quark.

**Architecture:** The client half is upstream libwayland, which already works —
it connects over a Quark socketpair given `WAYLAND_SOCKET` and marshals real
protocol down it. What is missing is the thing on the other end. So this builds
the **server** half of the Wayland wire protocol in `user/wm`, in Rust, over the
descriptors Phase 10 added: a socketpair per client, `SCM_RIGHTS` for the
buffer pool, and a descriptor set to wait on them all.

**Tech Stack:** Rust (`x86_64-unknown-none`, no_std) for the compositor;
upstream libwayland 1.23.1 + libffi 3.4.6 built with the musl cross toolchain
for the client. `wayland-scanner` runs on the host.

**Spec:** `docs/wayland.md` — in particular "Rules the compositor must honour",
which is the part that is about correctness rather than transport.

## Global Constraints

- **`-Db_staticpic=false` for every meson package.** meson compiles static
  libraries `-fPIC`; a Quark program is static, not PIE, and `-mcmodel=large`.
  In that combination the address of a default-visibility symbol comes out
  zero, a long way from where it is used.
- **The compositor is `no_std`.** No allocator, so every table is a fixed
  array, as everywhere else in `user/`.
- **`user/wm/src/main.rs` is 1247 lines already** and this roughly doubles it.
  It gets split, and the split is part of the first task rather than a promise.
- **A protocol object id is per client.** `msg.sender` from `sys_recv` is the
  kernel's, but a Wayland client is on a *stream*, not IPC — so the compositor
  knows which client a message came from by which descriptor it read.
- Verification is boot-in-QEMU and a QMP screendump; `user/dtest` is the
  pattern for anything assertable without a screen.
- Commit messages end with `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`
  and no session link.

Wayland's wire format is `[object: u32][opcode: u16 | size: u16][args]`, every
argument 32-bit aligned, strings length-prefixed and NUL-terminated with the

to get right and unforgiving enough that getting it wrong looks like a
different bug — so it is tested on its own, against bytes libwayland actually
produced.

```rust
    println!("wayland wire format:");
    // wl_display.get_registry as libwayland actually sent it: object 1,
    // opcode 1, size 12, one new_id argument of 2.
    let msg: [u8; 12] = [
        0x01, 0x00, 0x00, 0x00, // object 1
        0x01, 0x00, 0x0C, 0x00, // opcode 1, size 12
        0x02, 0x00, 0x00, 0x00, // new_id 2
    ];
    let h = wire::parse_header(&msg);
    check("a header parses", h.is_some());
    let h = h.unwrap();
    check("object is 1", h.object == 1);
    check("opcode is 1", h.opcode == 1);
    check("size is 12", h.size == 12);
    check("the argument is 2", wire::get_u32(&msg, 8) == Some(2));

    // Round trip.
    let mut out = [0u8; 12];
    wire::put_header(&mut out, wire::Header { object: 1, opcode: 1, size: 12 });
    wire::put_u32(&mut out, 8, 2);
    check("a header we write is the one libwayland wrote", out == msg);

    // A short buffer is not a header.
    check("a truncated header is refused", wire::parse_header(&msg[..7]).is_none());

    // Strings carry their NUL in the length and pad to four.
    let mut sb = [0u8; 16];
    let n = wire::put_str(&mut sb, 0, b"wl_shm");
    check("a string is length, bytes, NUL, padding", n == 12);
    check("its length includes the NUL", wire::get_u32(&sb, 0) == Some(7));
    check(
        "and it reads back",
        wire::get_str(&sb, 0).map(|(s, _)| s) == Some(&b"wl_shm"[..]),
    );
    check("padding rounds up to four", wire::pad4(7) == 8 && wire::pad4(8) == 8);
}
```

```rust
//! Wayland's wire format.
//!
//! `[object: u32][opcode: u16 | size: u16][arguments]`, every argument aligned
//! to four bytes. A string is a length, then that many bytes *including* a NUL,
//! then padding to four; an array is the same without the NUL. The size in the
//! header counts the header.
//!
//! Small enough to get right, and unforgiving enough that getting it wrong
//! looks like a bug somewhere else entirely — which is why it is tested against
//! bytes libwayland actually produced rather than against its own idea of them.

pub const HEADER: usize = 8;

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Header {
    pub object: u32,
    pub opcode: u16,
    pub size: u16,
}

pub fn parse_header(b: &[u8]) -> Option<Header> {
    if b.len() < HEADER {
        return None;
    }
    let object = u32::from_le_bytes([b[0], b[1], b[2], b[3]]);
    let word = u32::from_le_bytes([b[4], b[5], b[6], b[7]]);
    let size = (word >> 16) as u16;
    // A size that does not cover its own header is malformed, and believing it
    // would advance the read cursor by less than nothing.
    if (size as usize) < HEADER {
        return None;
    }
    Some(Header { object, opcode: (word & 0xFFFF) as u16, size })
}

pub fn put_header(b: &mut [u8], h: Header) {
    b[..4].copy_from_slice(&h.object.to_le_bytes());
    b[4..8].copy_from_slice(&(((h.size as u32) << 16) | h.opcode as u32).to_le_bytes());
}

pub fn get_u32(b: &[u8], at: usize) -> Option<u32> {
    if at + 4 > b.len() {
        return None;
    }
    Some(u32::from_le_bytes([b[at], b[at + 1], b[at + 2], b[at + 3]]))
}

pub fn put_u32(b: &mut [u8], at: usize, v: u32) {
    b[at..at + 4].copy_from_slice(&v.to_le_bytes());
}

/// Round up to the next multiple of four.
pub fn pad4(n: usize) -> usize {
    (n + 3) & !3
}

/// A string at `at`, and how many bytes it occupied including its padding.
pub fn get_str(b: &[u8], at: usize) -> Option<(&[u8], usize)> {
    let len = get_u32(b, at)? as usize;
    if len == 0 {
        return Some((&b[..0], 4));
    }
    let start = at + 4;
    // The length counts a NUL this returns without.
    if start + len > b.len() {
        return None;
    }
    Some((&b[start..start + len - 1], 4 + pad4(len)))
}

/// Write a string, returning how many bytes it took.
pub fn put_str(b: &mut [u8], at: usize, s: &[u8]) -> usize {
    let len = s.len() + 1;
    put_u32(b, at, len as u32);
    b[at + 4..at + 4 + s.len()].copy_from_slice(s);
    b[at + 4 + s.len()] = 0;
    for i in s.len() + 1..pad4(len) {
        b[at + 4 + i] = 0;
    }
    4 + pad4(len)
}
```

```c
/* What a Wayland client does before it draws anything. */
#define _GNU_SOURCE
#include <stdio.h>
#include <string.h>
#include <wayland-client.h>

static int count;
static void global(void *d, struct wl_registry *r, uint32_t name,
                   const char *iface, uint32_t version) {
    (void)d; (void)r;
    printf("  global %u: %s v%u\n", name, iface, version);
    count++;
}
static void global_remove(void *d, struct wl_registry *r, uint32_t name) {
    (void)d; (void)r; (void)name;
}
static const struct wl_registry_listener L = { global, global_remove };

int main(void) {
    struct wl_display *d = wl_display_connect(NULL);
    printf("connect: %s\n", d ? "OK" : "NULL");
    if (!d) return 1;
    struct wl_registry *r = wl_display_get_registry(d);
    wl_registry_add_listener(r, &L, NULL);
    printf("roundtrip: %d\n", wl_display_roundtrip(d));
    printf("globals: %d\n", count);
    wl_display_disconnect(d);
    return count > 0 ? 0 : 1;
}
```

- [x] **Step 3: Write the implementation**

The read path already uses `sys_fd_recv`; give it somewhere to put a descriptor
and note which message it arrived with. A descriptor arrives *with* the message
that needs it, so a client whose request carries one and whose bytes arrive
split across two reads must still see them paired — hold the descriptor with
the buffered bytes rather than with the read.

`shm.rs` maps a received descriptor with `sys_mmap_fd` at a per-pool address
from a fixed range, and a `Buffer` is an offset, a size and a stride within it.
Refuse a buffer whose extent runs past the pool: that is the check between a
client's arithmetic and the compositor reading memory that is not there.

Advertise `WL_SHM_FORMAT_XRGB8888` (0) and `ARGB8888` (1) with a `format` event
on bind, and refuse any other.

### Task 5: A surface, a role, and a commit

**Files:**
- Create: `user/wm/src/surface.rs`, `user/wm/src/shell.rs`
- Modify: `user/wm/src/main.rs`, `user/wm/src/client.rs`

**Interfaces:**
- Consumes: Tasks 3 and 4.
- Produces: `surface::Surface` with pending and current state;
  `surface::commit(idx)`; `shell::configure(idx)`.

This is where `docs/wayland.md`'s rules stop being prose. A surface means
nothing until `xdg_surface.get_toplevel` gives it a role; `attach`, `damage`
and `frame` accumulate *pending* state and `commit` applies all of it at once;
and the compositor sends `wl_buffer.release` when it has finished reading.

- [x] **Step 1: Write the failing test**

`wlprobe` becomes the full `weston-simple-shm` prologue: create a surface, get
an `xdg_surface` and an `xdg_toplevel`, commit, wait for the `configure`, ack
it, attach, damage, commit, and count `frame` callbacks over a second.

Expected before implementation: no `configure` arrives and the client waits.

- [x] **Step 2: Run it to verify it fails**

Boot, `wm wlprobe`. Expected: it hangs waiting for a configure. Use a
screendump after ten seconds rather than waiting for an exit.

- [x] **Step 3: Write the implementation**

Pending and current state as two structs of the same shape, with `commit`
copying one to the other and clearing the pending damage — the atomicity is
that copy and nothing else.

`xdg_surface.get_toplevel` sets the role and refuses a second one.
`xdg_surface.configure` is sent with a serial the client must `ack_configure`,
and a surface may not be shown before its first `ack`.

On `commit` with a buffer attached: composite through `draw::refresh_window`,
present the damaged region, then send `wl_buffer.release`. Send
`wl_callback.done` for any `frame` request on that surface, with the time in
milliseconds — that is what throttles the client, and without it
`weston-simple-shm` will draw as fast as it can.

- [x] **Step 4: Run it to verify it passes**

Boot, `wm wlprobe`, screendump. Expected: a window on screen with the client's
own pixels in it, and a frame count that advances at roughly the rate the
compositor presents rather than as fast as the client can loop.

- [x] **Step 5: Commit**

```bash
git add user/wm/src
# and in ../explosion: toolchain/wlprobe.c
git commit -m "$(cat <<'EOF'
A surface with a role, committed atomically, and its buffer given back

attach, damage and frame do nothing when they arrive: they accumulate pending
state, and commit applies all of it at once. That copy is the whole of the
atomicity, and it is what makes a half-drawn frame unrepresentable rather than
merely unlikely.

A surface means nothing until xdg_surface.get_toplevel gives it a role, and a
second role is refused. Nothing is shown before the client has acknowledged its
first configure.

wl_buffer.release is what lets a client reuse memory the compositor was
reading, and wl_callback.done is what stops it drawing faster than the screen.
Without the second, weston-simple-shm draws as fast as it can loop, which is
how an animating client used to keep this compositor too busy to read the
keyboard.

Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>
EOF
```

## Deliberately not in this plan

The spec's input rules — keyboard focus and pointer focus being separate, the
implicit grab, serials on input events — appear nowhere here, and that is the
decision made when the milestones were set rather than an omission.
`weston-simple-shm` binds no seat: it draws and never reads. Input is 8b and
8c, and the reason for the split is that the riskiest item in the whole phase
is the i8042 keyboard-and-mouse demultiplex, which can wedge the keyboard.
Coupling it to "does Wayland work at all" would make one failure look like the
other.

`xdg-decoration` is likewise deferred: the compositor draws a title bar of its
own for now, as it already does, and negotiating that with a client is a
conversation there is no second party for until a toolkit shows up.

## Acceptance

`weston-simple-shm`, taken from the weston tree and not edited, draws its
pattern in a window on Quark, throttled by frame callbacks, with its buffer
released between frames.

## Notes for whoever executes this

- **`-Db_staticpic=false`.** It fails a long way from its cause.
- **A stream is not a message.** Every read may deliver half a message or three;
  the read path must buffer and consume whole ones.
- **A descriptor belongs to a message, not to a read.** Hold it with the
  buffered bytes.
- **The compositor is `no_std` and has no allocator.** Fixed arrays, and refuse
  when full rather than growing.
- **libwayland disconnects on a protocol error** and says why on stderr, which
  is wired to the console. Read it; it is more precise than a screendump.
